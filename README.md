# Algoritmos e Lógica de Programação — Nelio Alves

Repositório com a resolução dos exercícios propostos no curso **Java e Programação Orientada a Objetos Expert**, do professor Nelio Alves. Os exercícios cobrem os fundamentos de algoritmos e lógica de programação, implementados em Java.

## 🎯 Objetivo

Consolidar a base de lógica de programação necessária para evoluir em Java e Orientação a Objetos, treinando os conceitos fundamentais que sustentam qualquer linguagem: entrada e saída de dados, tomada de decisão, repetição e manipulação de coleções de dados.

## 📚 Conteúdo abordado

O repositório está organizado de acordo com os principais tópicos do curso:

### 1. Estrutura Sequencial
Programas simples de entrada, processamento e saída de dados, sem desvios de fluxo — a base de qualquer algoritmo.

### 2. Estrutura Condicional
Exercícios com `if`, `else if`, `else` e operadores lógicos, trabalhando tomada de decisão e validação de dados.

### 3. Estruturas Repetitivas (Loops)
Exercícios com `while`, `do-while` e `for`, incluindo contadores, acumuladores e validação de entradas por repetição.

### 4. Vetores (Arrays)
Manipulação de listas de dados unidimensionais: preenchimento, busca, ordenação, maior/menor valor, médias, entre outros.

### 5. Matrizes
Manipulação de estruturas bidimensionais: preenchimento, percurso por linhas/colunas, diagonais e operações entre matrizes.
